# Handoff procedure

1. Record scope, root path, changed files, runtime/dependency choices, observed checks (including failures), unresolved evidence, and the next task in current.md. Do not include secrets or private data.
2. On resumption read current.md, README.md, AGENTS.md and relevant source; inspect Git status, verify the chosen interpreter and services, and run the smallest relevant check before making changes. Treat old process IDs and live-service states as historical observations.
